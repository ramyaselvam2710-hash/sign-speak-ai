{% if language == 'ta' %} 📌 திட்ட விளக்கம் {% else %} 📌 Project Description {% endif %}

{% if language == 'ta' %} Sign Speak AI என்பது செயற்கை நுண்ணறிவை அடிப்படையாகக் கொண்ட ஒரு பயன்பாடாகும். இது சைகை மொழி கை அசைவுகளை உரை மற்றும் குரலாக மாற்றுகிறது. இது காது கேளாத மற்றும் பேச முடியாத நபர்கள் மற்றவர்களுடன் எளிதாக தொடர்பு கொள்ள உதவுகிறது. {% else %} Sign Speak AI is an AI-based application that converts sign language gestures into text and voice output. It helps Deaf and Mute people communicate easily with normal people. {% endif %}

{% if language == 'ta' %} 🎯 நோக்கம் {% else %} 🎯 Objective {% endif %}

    {% if language == 'ta' %}
  • செயற்கை நுண்ணறிவைப் பயன்படுத்தி கை சைகைகளை கண்டறிதல்.
  • சைகை மொழியை ஆங்கிலம் மற்றும் தமிழ் உரையாக மாற்றுதல்.
  • சிறந்த தகவல் தொடர்புக்காக குரல் வெளியீட்டை வழங்குதல்.
  • உரையாடல் வரலாற்றை சேமித்தல்.
    • {% else %}
  • Recognize hand gestures using Artificial Intelligence.
  • Convert sign language into English and Tamil text.
  • Provide voice output for better communication.
  • Save conversation history.
    • {% endif %}
